# Bot Triage Comercial InterChile

Sistema de triage comercial y pre-diagnóstico técnico automatizado para atención vía WhatsApp/Telegram.
Desarrollado como proyecto de título (Hito 1 - MVP).

## Stack Tecnológico
- **Node.js**
- **Supabase** (Base de Datos Relacional)
- **Gemini LLM** (Procesamiento Semántico)

## Estrategia de Ramas (Git Flow)
- `main`: Código estable, liberado a producción.
- `develop` (o `dev`): Rama principal de desarrollo para integración continua.
- `feature/*`: Ramas para desarrollo de historias de usuario.

*(Esta configuración cumple con la rúbrica de Versionamiento del Hito 1).*
